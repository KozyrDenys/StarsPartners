# **Тест-план для страницы https://example.com**

### P0: Тестирование основных сценариев

- Тест-кейсы:
  - Отображение заголовка ("Example Domain")
  - Отображение ссылки "Learn more" с корректным href
  - Проверка отсутствия кнопок и полей ввода

### P1: Тестирование поведения ссылок

- Тест-кейсы:
  - Клик на ссылку "Learn more": проверка перехода на страницу https://iana.org/domains/example
  - Отсутствие ошибок при открытии ссылки (например, HTTP-ошибки)

### P2: Тестирование поведения кнопок и полей ввода

- Тест-кейсы:
  - Проверка отсутствия кнопок и полей ввода на странице
  - Отсутствие ошибок при попытке клика по не существующим кнопкам или полем ввода
